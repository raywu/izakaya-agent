# Japanese authenticity

The target is **contemporary, colloquial, polite, context-appropriate Japanese**.

## Validation states

- `draft`
- `research-validated`
- `agent-reviewed`
- `native-validated`
- `needs-review`

These are workflow labels, not mastery scores. Agent review never equals native review.

## Evidence preference

When validating curriculum language, prefer:
1. contemporary native Japanese usage;
2. primary Japanese restaurant/service materials;
3. qualified native-speaker review;
4. strong Japanese pedagogical references;
5. English-language learner resources.

Distinguish:
- grammatically possible;
- understandable;
- natural;
- natural in this exact service context.

## Runtime boundary

Trusted content supplies preferred production, staff recognition targets, pragmatic boundaries, and permitted variation. The runtime tutor should not invent Japanese and then call it the natural/preferred form.

## MVP native review

Before calling the first-drink content production-ready, review the compact fixture in `content/izakaya/first-drink.md` with a qualified native Japanese speaker. Keep its current `native review pending` labels until then.
