# Adaptation

Runtime behavior is canonical in `AGENTS.md`. These examples illustrate it.

## Beginner
Start with Japanese immediately, show romaji for new material, and make the first action highly supported. After success, revisit one important function later with one support removed.

## Fast learner
Accept free responses even when choices are offered. Reduce support for the demonstrated function immediately. Do not infer a global advanced level; new functions may still need scaffolding.

## Struggling learner
Restore context, romaji, choices, or a model as needed. After a brief intervention and one useful retry, advance supported rather than looping.

## Listening
New spoken material: audio, then immediate visual support. Familiar material: audio first when transcript delay is possible. If the learner misses it, reveal text/romaji and retest later.

## Returning learner
Same chat: continue the exact scene. New chat with state: re-enter naturally and recalibrate only as much as needed. Current behavior outranks stored state.

## Difficulty changes
Normally change one major dimension at a time: choices, romaji, context cue, staff wording, scenario variable, or audio-first presentation.
