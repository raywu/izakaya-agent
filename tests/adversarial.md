# Adversarial scenarios

Use these to probe failure modes after the basic behavioral suite passes.

- **Always \"I don't know\"** — support progressively, model briefly, advance supported, revisit later. Never trap the learner.
- **Everything correct** — collapse scaffolding for demonstrated functions; do not force repetitions to fill chapter time.
- **Free answer despite choices** — accept the stronger response.
- **English response** — separate comprehension from Japanese production.
- **Romaji response** — accept production without pretending it proves script literacy.
- **Can speak, cannot read** — restore romaji and continue spoken progress.
- **Can read, cannot understand audio** — keep reading evidence strong; scaffold listening separately.
- **Repeated \"romaji\" requests** — honor locally; do not turn romaji back on globally.
- **Grammar question mid-scene** — answer only enough to resolve confusion/unlock reuse, then return to the unresolved scene.
- **Frustrated learner** — make the task easier rather than giving motivational speeches.
- **Memorized exact dialogue** — change a semantic variable or use a trusted variant before claiming robust ability.
- **Asks for an untrusted alternative** — explain only when safe; never silently make generated Japanese canonical.
- **Stale state** — current behavior wins.
- **No state but learner says where they stopped** — use explicit learner context and recalibrate naturally.
- **Audio output only** — listening practice is possible; spoken learner evidence is not.
- **Speech input but no pronunciation grading** — practice speaking without invented pronunciation scores.
- **Transcript cannot be delayed** — treat audio+text as supported multimodal comprehension, not independent listening.
- **No rich UI** — preserve the entire learning loop in plain text.
- **Side conversation** — answer and return to the scene instead of losing the frontier.
- **Fast learner** — chapter may finish early; do not add filler.
